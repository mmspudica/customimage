# LUCE Lookbook MVP

LUCE 룩북은 동대문 도매 상품을 표준화된 형태로 정리하고, 셀러가 빠르게 셀렉션을 구성한 뒤 스튜디오 요청까지 이어지는 워크플로우를 돕는 전처리 도구입니다. 본 리포지터리는 투자/파일럿 데모용으로 제작된 정적 웹 애플리케이션을 담고 있습니다.

## 주요 섹션

- **룩북 퍼스트 화면**: 페이지 로드시 곧바로 룩북 그리드가 노출되며, 전체/패션/뷰티/건기식/잡화 필터로 공급업체가 등록한 실제 상품만 무한 스크롤로 탐색할 수 있습니다.
- **셀렉션 바구니**: 선택한 룩을 장바구니처럼 모아보고, 10초 룩시트 텍스트 파일을 자동으로 생성합니다.
- **스튜디오 셀렉션 체크아웃**: 셀렉션에서 바로 연결되는 스튜디오 요청 폼으로 방송 예약을 확정합니다.
- **체크리스트**: 도매 업로드 규칙, 스튜디오 준비, 교환/반품 기준을 한눈에 확인합니다.
- **회원가입 전용 화면**: 우측 상단 `회원가입` 버튼을 누르면 도매/셀러 가입 폼이 배치된 별도 페이지로 이동합니다.
- **공급업체 어드민**: 상단 내비게이션의 `어드민` 링크에서 공급업체 계정으로 상품 정보를 등록하고, 등록된 상품 현황을 실시간으로 확인할 수 있습니다.

## 실행 방법

### 1. 의존성 설치 및 서버 실행

Express 기반 경량 서버가 정적 페이지와 API를 함께 제공합니다.

```bash
cd server
npm install
npm start
```

서버가 기동되면 `http://localhost:3000`에서 애플리케이션을 열 수 있습니다. 모든 정적 페이지와 API(`*/api/*`)가 동일 포트에서 제공됩니다.

## 데모 흐름

1. 공급업체는 `회원가입` 페이지에서 도매 계정으로 등록한 뒤, `어드민` 페이지에서 상품을 업로드합니다.
2. 업로드된 상품은 곧바로 룩북 첫 화면에 반영되며, 카테고리 필터로 탐색할 수 있습니다.
3. 마음에 드는 상품을 `셀렉션 담기`로 추가합니다.
4. 셀렉션 요약 패널에서 룩시트를 자동 생성하거나 스튜디오 요청 섹션으로 이동합니다.
5. 스튜디오 요청 폼을 제출해 방송 일정을 확정합니다.

## 데이터베이스 구조

서버는 SQLite를 사용해 가입 및 상품 데이터를 `server/data/luce.db`에 저장합니다. `npm start` 실행 시 아래 테이블이 자동 생성됩니다.

### `signups`

| 컬럼 | 설명 |
| --- | --- |
| `id` | 기본 키 |
| `type` | `wholesale` 또는 `seller` |
| `brand` | 상호/브랜드명 |
| `phone` | 연락처 |
| `email` | 이메일 |
| `category` | 도매 주력 카테고리(도매 전용) |
| `channel` | 온라인 채널/링크 |
| `experience` | 셀러 라이브 경험치(셀러 전용) |
| `notes` | 비고 |
| `created_at` | 등록 시각 |

### `products`

| 컬럼 | 설명 |
| --- | --- |
| `id` | 기본 키 |
| `supplier_id` | `signups.id` 참조(공급업체) |
| `title` | 상품명 |
| `category` | `fashion`/`beauty`/`wellness`/`goods` |
| `retail_price` | 소매가(문자열 그대로 저장) |
| `fit` | 사이즈/구성 요약 |
| `specs` | 상세 스펙 |
| `description` | 상품 요약 |
| `primary_image` | 첫 번째 이미지 URL |
| `gallery` | JSON 배열 형태의 이미지 URL 목록 |
| `created_at` | 등록 시각 |

주요 API는 다음과 같습니다.

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `POST` | `/api/signup` | 도매/셀러 회원가입 저장 |
| `GET` | `/api/suppliers` | 도매(`wholesale`) 계정 목록 조회 |
| `POST` | `/api/products` | 공급업체 상품 업로드 |
| `GET` | `/api/products` | 룩북 노출용 상품 목록 조회 |

## 폴더 구조

```
├── index.html        # 메인 페이지
├── admin.html        # 공급업체 상품 관리 페이지
├── signup.html       # 도매/셀러 회원가입 페이지
├── styles/
│   └── style.css     # 전체 스타일 시트
├── scripts/
│   ├── app.js        # 룩북, 셀렉션, 폼 로직
│   └── admin.js      # 어드민 상품 업로드/목록 로직
└── server/
    ├── index.js      # Express + SQLite API 서버
    └── package.json  # 서버 의존성 및 실행 스크립트
```

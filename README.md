# LUCE Lookbook MVP

LUCE 룩북은 동대문 도매 상품을 표준화된 형태로 정리하고, 셀러가 빠르게 셀렉션을 구성한 뒤 스튜디오 요청까지 이어지는 워크플로우를 돕는 전처리 도구입니다. 본 리포지터리는 투자/파일럿 데모용으로 제작된 정적 웹 애플리케이션을 담고 있습니다.

## 주요 섹션

- **룩북**: 카테고리 필터와 함께 최신 상품 카드를 보여주고, 실측/혼용률 등 필수 정보를 정리합니다.
- **셀렉션 바구니**: 선택한 룩을 장바구니처럼 모아보고, 10초 룩시트 텍스트 파일을 자동으로 생성합니다.
- **스튜디오 요청**: 날짜, 채널, 메모를 입력 받아 운영팀과 공유할 수 있는 간단한 양식을 제공합니다.
- **체크리스트**: 도매 업로드 규칙, 스튜디오 준비, 교환/반품 기준을 한눈에 확인합니다.
- **도매/셀러 회원가입**: 각 파트너 유형별로 필요한 정보를 수집하는 가입 폼을 제공합니다.

## 실행 방법

정적 사이트로, 별도의 빌드 과정 없이 브라우저에서 바로 확인할 수 있습니다.

```bash
# 프로젝트 루트에서 간단한 개발 서버 실행
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속하면 애플리케이션을 확인할 수 있습니다.

## 데모 흐름

1. 룩북에서 카테고리를 필터링하며 상품을 탐색합니다.
2. 마음에 드는 상품을 `셀렉션 담기`로 추가합니다.
3. 셀렉션 요약 패널에서 룩시트를 자동 생성하거나 스튜디오 요청 섹션으로 이동합니다.
4. 스튜디오 요청 폼을 제출하면 확인 메시지가 표시됩니다.
5. 도매/셀러 가입 폼을 통해 파트너 정보를 접수할 수 있습니다.


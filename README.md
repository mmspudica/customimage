# LUCE Lookbook MVP

LUCE 룩북은 동대문 공급업체 상품을 표준화된 형태로 정리하고, 셀러가 빠르게 셀렉션을 구성한 뒤 스튜디오 요청까지 이어지는 워크플로우를 돕는 전처리 도구입니다. 본 리포지터리는 투자/파일럿 데모용으로 제작된 정적 웹 애플리케이션을 담고 있습니다.

## 주요 섹션

- **룩북 퍼스트 화면**: 페이지 진입 시 다른 섹션을 모두 접어 두고 룩북 그리드만 집중 노출합니다. 상단 메트릭 카드에서 현재 등록된 룩·공급업체·셀러 수와 최신 업데이트 시각을 확인하고, 전체/패션/뷰티/건기식/잡화 필터로 공급업체가 등록한 실제 상품을 무한 스크롤로 탐색할 수 있습니다. 초기 데이터로 패션/뷰티/건기식/잡화 카테고리별 5개씩 총 20개의 룩 시트가 준비되어 있으며, 각 카드에는 썸네일과 5장의 상세 이미지가 포함되어 데스크톱에서는 호버 시, 모바일에서는 화면 노출 시 1초 간격으로 회전합니다.
- **셀렉션 바구니**: 상단 내비게이션에서 `셀렉션`을 선택하면 장바구니 모드가 열리고, 10초 룩시트 텍스트 파일을 자동으로 생성합니다.
- **스튜디오 셀렉션 체크아웃**: 내비게이션의 `스튜디오 셀렉션` 진입 시 스튜디오 요청 폼으로 바로 연결되어 방송 예약을 확정합니다.
- **체크리스트**: `체크리스트` 섹션에서 공급업체 업로드 규칙, 스튜디오 준비, 교환/반품 기준을 한눈에 확인합니다.
- **회원가입 전용 화면**: 우측 상단 `회원가입` 버튼을 누르면 공급업체/셀러/일반회원 유형을 선택하고 각각의 가입 페이지로 이동합니다.
- **공급업체 어드민**: 상단 내비게이션의 `어드민` 링크에서 공급업체 계정으로 로그인 후 상품을 등록하고, 썸네일·상세 이미지를 직접 업로드하면서 등록 현황을 실시간으로 확인할 수 있습니다.

## 실행 방법

### 1. 의존성 설치 및 서버 실행

Express 기반 경량 서버가 정적 페이지와 API를 함께 제공합니다.

```bash
cd server
npm install
npm start
```

서버가 기동되면 `http://localhost:3000`에서 애플리케이션을 열 수 있습니다. 모든 정적 페이지와 API(`*/api/*`)가 동일 포트에서 제공됩니다.
이미지 업로드 파일은 `server/data/uploads` 폴더에 저장되며, 클라이언트에서는 `/uploads/{파일명}` 경로로 접근합니다.

## 데모 흐름

1. 공급업체는 `회원가입` 선택 페이지에서 공급업체 유형으로 등록한 뒤, `어드민` 페이지 혹은 `login.html`에서 이메일/비밀번호로 로그인합니다. 데모 확인용 기본 계정은 `demo-supplier@luce.app / luce1234` 입니다.
2. 업로드된 상품은 곧바로 룩북 첫 화면에 반영되며, 카테고리 필터로 탐색할 수 있습니다.
3. 마음에 드는 상품을 `셀렉션 담기`로 추가합니다.
4. 셀렉션 요약 패널에서 룩시트를 자동 생성하거나 스튜디오 요청 섹션으로 이동합니다.
5. 스튜디오 요청 폼을 제출해 방송 일정을 확정합니다.

## 데이터베이스 구조

서버는 SQLite를 사용해 가입 및 상품 데이터를 `server/data/luce.db`에 저장합니다. `npm start` 실행 시 아래 테이블이 자동 생성됩니다.

### `signups`

| 컬럼 | 설명 |
| --- | --- |
| `id` | 기본 키 |
| `type` | `supplier`, `seller`, `member` |
| `brand` | 상호/브랜드명 |
| `phone` | 연락처 |
| `email` | 이메일 |
| `password_hash` | 로그인 비밀번호 해시 |
| `category` | 주력 카테고리 |
| `channel` | 온라인 채널/링크 |
| `experience` | 셀러 라이브 경험치(셀러 전용) |
| `notes` | 비고 |
| `created_at` | 등록 시각 |

### `products`

| 컬럼 | 설명 |
| --- | --- |
| `id` | 기본 키 |
| `supplier_id` | `signups.id` 참조(공급업체) |
| `title` | 상품명 |
| `category` | `fashion`/`beauty`/`wellness`/`goods` |
| `retail_price` | 소매가(문자열 그대로 저장) |
| `fit` | 사이즈/구성 요약 |
| `specs` | 상세 스펙 |
| `description` | 상품 요약 |
| `primary_image` | 업로드된 썸네일 파일의 상대 경로(`/uploads/…`) |
| `gallery` | JSON 배열 형태의 상세 이미지 상대 경로 목록 |
| `created_at` | 등록 시각 |

주요 API는 다음과 같습니다.

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `POST` | `/api/signup` | 공급업체/셀러/일반회원 가입 저장 |
| `POST` | `/api/login` | 공급업체 로그인 (이메일/비밀번호) |
| `POST` | `/api/logout` | 공급업체 로그아웃 |
| `GET` | `/api/session` | 현재 로그인한 공급업체 세션 조회 |
| `GET` | `/api/suppliers` | 공급업체 계정 목록 조회 |
| `POST` | `/api/products` | 공급업체 상품 업로드 |
| `GET` | `/api/products` | 룩북 노출용 상품 목록 조회 |
| `GET` | `/api/metrics` | 상품/회원 지표 조회 |

## 기본 제공 데이터

- **샘플 룩북**: 패션/뷰티/건기식/잡화 카테고리별 5개씩 총 20개의 룩이 선등록되어 있습니다. 각 상품은 썸네일 포함 5장의 상세 이미지를 1초 간격으로 순환하며 모바일에서는 화면에 표시되는 동안 자동 재생됩니다.
- **계정 풀**: 서버 기동 시 공급업체 100개, 셀러 1,000명, 일반회원 2,000명이 자동으로 채워져 메트릭 카드와 리스트형 화면에서 즉시 확인할 수 있습니다.
- **데모 로그인**: 공급업체 기본 계정은 `demo-supplier@luce.app / luce1234`이며, 나머지 자동 생성 계정은 `supplierXXX@demo.luce`, `sellerXXXX@demo.luce`, `memberXXXX@demo.luce` 패턴으로 구성되어 있습니다. 모든 자동 생성 계정의 기본 비밀번호는 `luce1234` 입니다.
- **데이터 저장소**: 실제 업로드 파일은 `server/data/uploads`에 저장되며, 샘플 룩은 Unsplash 이미지를 참조해 별도 설치 없이 즉시 데모를 실행할 수 있습니다.

## 폴더 구조

```
├── index.html        # 메인 페이지
├── admin.html        # 공급업체 상품 관리 페이지
├── login.html        # 공급업체 로그인 페이지
├── signup.html       # 회원 유형 선택 페이지
├── supplier-signup.html # 공급업체 회원가입 페이지
├── seller-signup.html   # 셀러 회원가입 페이지
├── member-signup.html   # 일반회원 가입 페이지
├── styles/
│   └── style.css     # 전체 스타일 시트
├── scripts/
│   ├── app.js        # 룩북, 셀렉션, 폼 로직
│   ├── admin.js      # 어드민 상품 업로드/목록 로직
│   └── auth.js       # 공급업체 로그인 처리
└── server/
    ├── index.js      # Express + SQLite API 서버
    └── package.json  # 서버 의존성 및 실행 스크립트
```

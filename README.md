# LUCE Lookbook MVP

LUCE 룩북은 동대문 도매 상품을 표준화된 형태로 정리하고, 셀러가 빠르게 셀렉션을 구성한 뒤 스튜디오 요청까지 이어지는 워크플로우를 돕는 전처리 도구입니다. 본 리포지터리는 투자/파일럿 데모용으로 제작된 정적 웹 애플리케이션을 담고 있습니다.

## 주요 섹션

- **룩북 퍼스트 화면**: 페이지 로드시 곧바로 룩북 그리드가 노출되며, 전체/패션/뷰티/건기식/잡화/기타 필터와 함께 무한 스크롤로 룩시트를 이어서 탐색할 수 있습니다.
- **셀렉션 바구니**: 선택한 룩을 장바구니처럼 모아보고, 10초 룩시트 텍스트 파일을 자동으로 생성합니다.
- **스튜디오 셀렉션 체크아웃**: 셀렉션에서 바로 연결되는 스튜디오 요청 폼으로 방송 예약을 확정합니다.
- **체크리스트**: 도매 업로드 규칙, 스튜디오 준비, 교환/반품 기준을 한눈에 확인합니다.
- **회원가입 전용 화면**: 우측 상단 `회원가입` 버튼을 누르면 도매/셀러 가입 폼이 배치된 별도 페이지로 이동합니다.

## 실행 방법

### 1. 의존성 설치 및 서버 실행

Express 기반 경량 서버가 정적 페이지와 API를 함께 제공합니다.

```bash
cd server
npm install
npm start
```

서버가 기동되면 `http://localhost:3000`에서 애플리케이션을 열 수 있습니다.

## 데모 흐름

1. 룩북에서 카테고리를 필터링하며 상품을 탐색합니다.
2. 마음에 드는 상품을 `셀렉션 담기`로 추가합니다.
3. 셀렉션 요약 패널에서 룩시트를 자동 생성하거나 스튜디오 요청 섹션으로 이동합니다.
4. 스튜디오 요청 폼을 제출해 방송 일정을 확정합니다.
5. 헤더의 `회원가입` 버튼을 눌러 도매/셀러 가입 페이지에서 정보를 전송합니다.

## 데이터베이스 구조

서버는 SQLite를 사용해 가입 데이터를 `server/data/luce.db`에 저장합니다. 테이블 스키마는 다음과 같습니다.

| 컬럼 | 설명 |
| --- | --- |
| `id` | 기본 키 |
| `type` | `wholesale` 또는 `seller` |
| `brand` | 상호/브랜드명 |
| `phone` | 연락처 |
| `email` | 이메일 |
| `category` | 도매 주력 카테고리(도매 전용) |
| `channel` | 온라인 채널/링크 |
| `experience` | 셀러 라이브 경험치(셀러 전용) |
| `notes` | 비고 |
| `created_at` | 등록 시각 |

`npm start` 실행 시 테이블이 자동으로 생성되며, `/api/signups` GET 요청으로 누적 데이터를 조회할 수 있습니다.

## 폴더 구조

```
├── index.html        # 메인 페이지
├── signup.html       # 도매/셀러 회원가입 페이지
├── styles/
│   └── style.css     # 전체 스타일 시트
├── scripts/
│   └── app.js        # 룩북 데이터, 필터, 셀렉션, 폼 로직
└── server/
    ├── index.js      # Express + SQLite API 서버
    └── package.json  # 서버 의존성 및 실행 스크립트
```

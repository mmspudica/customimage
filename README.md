# LUCE Lookbook MVP

LUCE 룩북은 동대문 공급업체 상품을 표준화된 형태로 정리하고, 셀러가 빠르게 셀렉션을 구성한 뒤 스튜디오 요청까지 이어지는 워크플로우를 돕는 전처리 도구입니다. 본 리포지터리는 투자/파일럿 데모용으로 제작된 정적 웹 애플리케이션을 담고 있습니다.

## 주요 섹션

- **룩북 퍼스트 화면**: 페이지 진입 시 다른 섹션을 모두 접어 두고 룩북 그리드만 집중 노출합니다. 상단 메트릭 카드에서 현재 등록된 룩·공급업체·셀러 수와 최신 업데이트 시각을 확인하고, 전체/패션/뷰티/건기식/잡화 필터로 공급업체가 등록한 실제 상품을 무한 스크롤로 탐색할 수 있습니다.
- **셀렉션 바구니**: 상단 내비게이션에서 `셀렉션`을 선택하면 장바구니 모드가 열리고, 10초 룩시트 텍스트 파일을 자동으로 생성합니다.
- **스튜디오 셀렉션 체크아웃**: 내비게이션의 `스튜디오 셀렉션` 진입 시 스튜디오 요청 폼으로 바로 연결되어 방송 예약을 확정합니다.
- **체크리스트**: `체크리스트` 섹션에서 공급업체 업로드 규칙, 스튜디오 준비, 교환/반품 기준을 한눈에 확인합니다.
- **회원가입 전용 화면**: 우측 상단 `회원가입` 버튼을 누르면 공급업체/셀러/일반회원 유형을 선택하고 각각의 가입 페이지로 이동합니다.
- **공급업체 어드민**: 상단 내비게이션의 `어드민` 링크에서 공급업체 계정으로 로그인 후 상품을 등록하고, 썸네일·상세 이미지를 직접 업로드하면서 등록 현황을 실시간으로 확인할 수 있습니다.

## 실행 방법

이 데모는 정적 파일만으로 작동합니다. 별도의 백엔드나 데이터베이스가 필요하지 않으며, 원하는 정적 서버로 페이지를 열 수 있습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/index.html`에 접속하면 룩북 첫 화면이 표시됩니다. 또는 `index.html` 파일을 직접 열어도 동일하게 이용할 수 있습니다.

모든 데이터는 브라우저 `localStorage`에 저장됩니다. 데모 상태를 초기화하고 싶다면 개발자 도구에서 `localStorage` 항목을 비우거나 `localStorage.clear()`를 실행하세요.

## 데모 흐름

1. 우측 상단 `회원가입` 페이지에서 공급업체/셀러/일반회원 유형 중 하나를 선택해 정보를 입력하면, 해당 정보가 브라우저 저장소에 누적됩니다.
2. 공급업체는 `login.html` 또는 `어드민` 링크에서 이메일/비밀번호로 로그인합니다. (샘플 계정: `test@test.com` / `test1234`)
3. 어드민에서 썸네일·상세 이미지를 업로드하면 파일이 브라우저 메모리에 data URL 형태로 저장되고, 룩북 첫 화면에 즉시 반영됩니다.
4. 룩북 카드에서 `셀렉션 담기` 버튼을 눌러 원하는 룩을 모으고, 요약 패널에서 자동 룩시트를 생성하거나 `스튜디오 셀렉션` 섹션으로 이동합니다.
5. `스튜디오 셀렉션` 폼에 방송 정보를 입력하면 접수 안내 메시지가 표시됩니다.

## 데모 데이터 & 계정

- 패션/뷰티/건기식/잡화 카테고리별로 5개씩 총 20개의 룩 샘플이 기본 제공됩니다.
- 각 상품은 썸네일을 포함해 5장의 상세 이미지를 갖고 있으며, 마우스 오버 또는 모바일 노출 시 1초 간격으로 순환합니다.
- 메트릭 카드는 공급업체 100곳, 셀러 1,000명, 일반회원 2,000명으로 초기화된 수치를 표시합니다.
- 공급업체 로그인 샘플 계정은 `test@test.com` / `test1234` 입니다. 이 계정으로 로그인하면 어드민에서 상품을 추가해 바로 테스트할 수 있습니다.
- 어드민에서 새 상품을 등록하면 룩북과 메트릭 카드가 즉시 업데이트됩니다. 데이터는 현재 브라우저에만 저장되며 새 브라우저/기기에서 다시 접속하면 기본 20개 샘플이 로드됩니다.

## 폴더 구조

```
├── index.html        # 메인 페이지
├── admin.html        # 공급업체 상품 관리 페이지
├── login.html        # 공급업체 로그인 페이지
├── signup.html       # 회원 유형 선택 페이지
├── supplier-signup.html # 공급업체 회원가입 페이지
├── seller-signup.html   # 셀러 회원가입 페이지
├── member-signup.html   # 일반회원 가입 페이지
├── styles/
│   └── style.css     # 전체 스타일 시트
├── scripts/
│   ├── demo-data.js  # 데모 데이터와 localStorage 관리
│   ├── app.js        # 룩북, 셀렉션, 폼 로직
│   ├── admin.js      # 어드민 상품 업로드/목록 로직
│   └── auth.js       # 공급업체 로그인 처리
└── server/           # 이전 백엔드 실험용 코드 (데모 실행에는 불필요)
    ├── index.js      # Express + SQLite API 서버 샘플
    └── package.json  # 서버 의존성 및 실행 스크립트
```
데모는 정적 자산만으로 동작하므로 `server/` 디렉터리는 참고용으로 남겨져 있으며 실행하지 않아도 됩니다.

## 라이선스

데모 목적으로만 사용 가능합니다.

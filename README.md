# LUCE Lookbook Demo

LUCE 룩북은 “도매가 올리고, 셀러가 고르면, 스튜디오가 준비한다”는 흐름을 빠르게 보여주기 위한 프론트엔드 데모입니다. 본 리포지터리는 데이터베이스나 서버 없이 정적 파일과 브라우저 로컬 스토리지만으로 동작하도록 구성되어 있습니다.

## 주요 기능

- **룩북 퍼스트 랜딩**: 진입과 동시에 룩북이 펼쳐지며, 패션/뷰티/건기식/잡화 네 가지 카테고리를 필터로 전환할 수 있습니다. 20개의 샘플 룩은 썸네일과 5장의 상세 이미지가 1초 간격으로 회전하고, 모바일 터치 환경에서는 화면에 노출된 동안 자동으로 슬라이드됩니다.
- **무한 스크롤 & 모달**: 배치 단위로 로드되는 무한 스크롤 그리드와 룩 클릭 시 팝업으로 표시되는 상세 정보를 통해 라이브 전처리 경험을 재현했습니다.
- **셀렉션 & 스튜디오 요청**: “셀렉션 담기” 버튼으로 장바구니를 구성하고, 텍스트 룩시트를 복사하거나 스튜디오 요청 폼을 제출해 데모 플로우를 이어갈 수 있습니다.
- **정적 메트릭 카드**: 공급업체 100개, 셀러풀 1,000개, 일반 회원 2,000명 등 투자 피치용 핵심 지표를 상단 카드로 노출합니다.
- **공급업체/셀러/일반 회원 가입 양식**: 각 유형별 가입 페이지를 제공하며 제출 시 입력 내용은 로컬 스토리지에 저장되어 데모 이후에도 남습니다.
- **공급업체 어드민 데모**: 상단 내비게이션의 “어드민”에서 공급업체로 로그인하면(샘플 계정 제공) 상품 업로드 폼과 등록 현황 테이블을 확인할 수 있습니다. 업로드한 이미지는 브라우저 메모리에 즉시 미리 보기용으로 저장되고, 메인 룩북에도 반영됩니다.

## 실행 방법

정적 파일만 필요하므로 별도의 빌드나 서버 설치 없이 실행할 수 있습니다. 아래 방법 중 하나를 선택하세요.

```bash
# Python 내장 서버 (예: macOS, Linux, Windows WSL)
python -m http.server 8000
```

혹은 `npm`이 설치되어 있다면 다음과 같이 실행할 수 있습니다.

```bash
npx serve .
```

서버를 띄운 뒤 브라우저에서 `http://localhost:8000`(또는 선택한 포트)을 열면 됩니다.

## 샘플 데이터 & 계정

- **룩 샘플 20개**: 패션/뷰티/건기식/잡화 각 5개씩, 썸네일과 연동된 5장의 상세 이미지를 포함합니다.
- **지표 카드**: 공급업체 100개, 셀러풀 1,000개, 일반회원 2,000명이 고정된 값으로 표시됩니다.
- **공급업체 테스트 계정**: `test@test.com` / `test1234`
  - 로그인 후 어드민에서 상품을 업로드하면 이미지가 로컬 스토리지에 저장되고 룩북 그리드에도 즉시 나타납니다.
- **가입 데이터 저장 위치**: 브라우저 로컬 스토리지(`luce-demo-*` 키)를 사용합니다. 데모 데이터를 초기화하고 싶다면 개발자 도구에서 해당 키를 삭제하거나 브라우저 저장소를 비우면 됩니다.

## 파일 구조

```
├── index.html              # 룩북 메인 페이지
├── admin.html              # 공급업체 어드민 데모
├── login.html              # 공급업체 로그인 화면
├── signup.html             # 회원 유형 선택 페이지
├── supplier-signup.html    # 공급업체 가입 양식
├── seller-signup.html      # 셀러 가입 양식
├── member-signup.html      # 일반회원 가입 양식
├── assets/
│   └── luce-logo.svg       # 제공된 LUCE 로고
├── scripts/
│   ├── demo-data.js        # 샘플 룩, 계정, 로컬 스토리지 유틸리티
│   ├── app.js              # 룩북·셀렉션·가입 폼 인터랙션
│   ├── admin.js            # 어드민 상품 업로드/목록 로직
│   └── auth.js             # 공급업체 로그인 처리
└── styles/
    └── style.css           # 전역 스타일
```

## 데모 노트

- 모든 데이터는 프론트엔드에서만 관리되므로, 새로고침 시에도 로컬 스토리지에 저장된 상품과 가입 정보가 유지됩니다.
- 이미지 업로드는 데모 목적의 간이 구현으로, 실제 서비스에서는 별도 파일 스토리지와 백엔드 검증이 필요합니다.
- 추가 샘플 데이터를 구성하려면 `scripts/demo-data.js`의 `LOOKS` 배열을 수정하면 됩니다.
